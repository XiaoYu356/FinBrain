# 股票投资指南

## 一、股票基础知识

### 1.1 什么是股票

股票是股份公司发行的所有权凭证，是股份公司为筹集资金而发行给各个股东作为持股凭证并借以取得股息和红利的一种有价证券。每股股票都代表股东对企业拥有一个基本单位的所有权。

### 1.2 股票的分类

**按股东权利分类**：
- **普通股**：享有投票权、分红权，但分红顺序排在优先股之后
- **优先股**：享有优先分红权，但通常没有投票权

**按上市地点分类**：
- **A股**：人民币普通股票，在中国境内上市
- **B股**：人民币特种股票，以美元或港币交易
- **H股**：在香港上市的中资企业股票
- **N股**：在纽约上市的中资企业股票

**按市值规模分类**：
- **大盘股**：市值超过500亿的公司
- **中盘股**：市值在100亿-500亿之间
- **小盘股**：市值低于100亿的公司

### 1.3 股票交易规则

**交易时间**：
- 周一至周五（法定节假日除外）
- 上午：9:30-11:30
- 下午：13:00-15:00

**交易单位**：
- 买入必须是100股（1手）的整数倍
- 卖出可以零股交易

**涨跌幅限制**：
- 主板股票：±10%
- 创业板/科创板：±20%
- ST股票：±5%
- 新股上市首日：不设涨跌幅限制

## 二、股票分析方法

### 2.1 基本面分析

基本面分析是通过分析公司的财务状况、行业地位、发展前景等因素来判断股票价值的方法。

**财务指标**：
- **市盈率（PE）**：股价/每股收益，反映投资回收期
- **市净率（PB）**：股价/每股净资产，反映估值水平
- **净资产收益率（ROE）**：净利润/净资产，反映盈利能力
- **毛利率**：（营收-成本）/营收，反映产品竞争力

**分析维度**：
1. 宏观经济环境
2. 行业发展趋势
3. 公司竞争地位
4. 管理团队能力
5. 财务健康状况

### 2.2 技术面分析

技术面分析是通过研究股票价格和成交量的历史数据来预测未来走势的方法。

**常用技术指标**：
- **移动平均线（MA）**：反映股价趋势
- **相对强弱指标（RSI）**：判断超买超卖
- **MACD**：判断趋势和买卖点
- **KDJ**：判断短期买卖时机
- **成交量**：验证价格走势

**K线形态**：
- 阳线：收盘价高于开盘价
- 阴线：收盘价低于开盘价
- 十字星：开盘价等于收盘价

## 三、股票投资策略

### 3.1 价值投资

价值投资是指以低于内在价值的价格买入优质公司股票，等待价值回归的投资策略。

**核心原则**：
1. 选择优质公司
2. 等待合理价格
3. 长期持有
4. 安全边际

**代表人物**：巴菲特、格雷厄姆

### 3.2 成长投资

成长投资是指投资于具有高增长潜力的公司，分享公司成长带来的收益。

**特征**：
- 营收和利润快速增长
- 所处行业前景广阔
- 具有核心竞争力
- 估值可能较高

### 3.3 趋势投资

趋势投资是指跟随市场趋势进行买卖的投资策略。

**操作原则**：
1. 顺势而为
2. 及时止损
3. 让利润奔跑
4. 控制仓位

## 四、风险管理

### 4.1 分散投资

不要把所有资金投入单一股票，建议：
- 持有5-10只不同行业的股票
- 单只股票仓位不超过20%
- 保留部分现金应对风险

### 4.2 止损策略

设置止损点，控制单笔亏损：
- 固定比例止损：如亏损8%止损
- 技术止损：跌破支撑位止损
- 时间止损：一定时间内未达预期止损

### 4.3 仓位管理

根据市场环境调整仓位：
- 牛市：可适当提高仓位
- 熊市：降低仓位，保留现金
- 震荡市：中等仓位，高抛低吸

## 五、常见投资误区

### 5.1 追涨杀跌

看到股票上涨就追入，下跌就恐慌卖出，容易造成高买低卖。

### 5.2 听消息炒股

盲目听信小道消息或他人推荐，不做独立分析。

### 5.3 频繁交易

过度交易增加成本，降低收益。

### 5.4 满仓操作

满仓买入后无法应对市场变化，风险过于集中。

### 5.5 不设止损

亏损后不愿止损，导致小亏变大亏。
