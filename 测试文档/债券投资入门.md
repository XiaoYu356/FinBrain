# 债券投资入门

## 一、债券基础概念

### 1.1 什么是债券

债券是一种金融契约，是政府、金融机构、工商企业等直接向社会借债筹措资金时，向投资者发行，承诺按一定利率支付利息并按约定条件偿还本金的债权债务凭证。

### 1.2 债券的基本要素

- **面值**：债券的票面价值
- **票面利率**：债券发行时确定的利率
- **期限**：债券的存续时间
- **发行人**：债券的发行主体
- **付息方式**：利息支付的方式和时间

### 1.3 债券的分类

**按发行主体分类**：
- **国债**：中央政府发行，信用等级最高
- **地方政府债**：地方政府发行
- **金融债**：金融机构发行
- **企业债**：企业发行
- **公司债**：上市公司发行

**按期限分类**：
- **短期债券**：期限1年以内
- **中期债券**：期限1-10年
- **长期债券**：期限10年以上

**按利息支付方式分类**：
- **附息债券**：定期支付利息
- **零息债券**：折价发行，到期按面值偿还
- **浮动利率债券**：利率随基准利率变动

## 二、债券投资收益

### 2.1 收益来源

债券投资的收益主要来自三个方面：
1. **票面利息**：定期获得的利息收入
2. **资本利得**：债券价格变动带来的收益
3. **再投资收益**：利息再投资获得的收益

### 2.2 收益率计算

**名义收益率** = 票面利息 / 面值

**当期收益率** = 票面利息 / 当前价格

**到期收益率（YTM）**：持有债券到期获得的年化收益率，是最常用的收益率指标。

### 2.3 债券价格与利率的关系

债券价格与市场利率呈反比关系：
- 市场利率上升 → 债券价格下降
- 市场利率下降 → 债券价格上涨

## 三、债券投资风险

### 3.1 利率风险

市场利率变动导致债券价格波动的风险。期限越长，利率风险越大。

### 3.2 信用风险

发行人无法按时支付利息或偿还本金的风险。

**信用评级**：
- AAA级：最高信用等级
- AA级：高级
- A级：中上级
- BBB级：中级
- BB级及以下：投机级（垃圾债）

### 3.3 流动性风险

债券无法及时变现或变现成本过高的风险。

### 3.4 通货膨胀风险

通货膨胀导致债券实际收益下降的风险。

### 3.5 再投资风险

市场利率下降导致利息再投资收益降低的风险。

## 四、债券投资策略

### 4.1 持有到期策略

买入债券后持有到期，获得稳定的利息收入。适合风险承受能力较低的投资者。

### 4.2 利率预测策略

根据对利率走势的判断进行买卖：
- 预期利率下降 → 买入长期债券
- 预期利率上升 → 卖出长期债券或持有短期债券

### 4.3 骑乘策略

买入期限较长的债券，随着时间推移，债券期限缩短，收益率下降，价格上涨获利。

### 4.4 套利策略

利用不同市场或不同债券之间的价格差异进行套利。

## 五、债券基金投资

### 5.1 债券基金的优势

- 专业管理：由专业基金经理管理
- 分散风险：投资多只债券，分散信用风险
- 门槛较低：小额资金也能参与
- 流动性好：可随时申购赎回

### 5.2 债券基金的分类

- **纯债基金**：只投资债券，风险最低
- **一级债基**：可参与新股申购
- **二级债基**：可投资股票，风险较高
- **指数债基**：跟踪债券指数

### 5.3 如何选择债券基金

1. 看基金经理：从业年限、历史业绩
2. 看基金规模：适中为好，太大太小都不利
3. 看费率：管理费、托管费、申购费
4. 看持仓：债券类型、久期、信用等级
